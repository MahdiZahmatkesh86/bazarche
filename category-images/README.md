# راهنمای عکس دسته‌بندی

## چطور عکس بذارم؟

۱) عکس‌ها رو توی همین پوشه بریز
۲) اسم فایل = اسم دقیق دسته

مثال:
- موبایل.jpg
- همبرگر.png
- پوشاک.jpeg

## نکات مهم
- اسم فایل باید **دقیقاً** با اسم دسته توی دیتابیس یکی باشه
- پسوندهای مجاز: jpg, jpeg, png, webp, gif
- بهترین اندازه: مربع (مثلاً 500×500)
- حداقل 200×200، حداکثر 2000×2000

## اجرا
بعد از ریختن عکس‌ها، این دستور رو بزن:
\`\`\`
node setup-category-images.js
\`\`\`

اسکریپت عکس‌ها رو پیدا می‌کنه، به uploads منتقل می‌کنه و توی DB ذخیره می‌کنه.
